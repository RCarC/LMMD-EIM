# 3D Prototypes

This section contains downloadable **3D prototypes** and associated technical resources developed at **LMMD - EIM**.

Each prototype should have its own folder. Depending on the project, it may include:

- STL files for 3D printing
- STEP files for interoperability and editing
- Native CAD source files
- Technical documentation
- Assembly or usage instructions
- Reference images or renders

## Suggested structure

```text
Prototipo-001/
├── README.md
├── STL/
├── STEP/
├── CAD/
└── Images/
```

The README inside each prototype folder should describe its purpose, version, compatibility, included files, and applicable license.
