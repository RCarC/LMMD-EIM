# Plantillas de planos normalizados — Autodesk Inventor

Plantillas institucionales para la elaboración de **planos técnicos en Autodesk Inventor** de la **Escuela de Ingeniería Mecánica (EIM), Pontificia Universidad Católica de Valparaíso (PUCV)**.

El objetivo de estas plantillas es facilitar el uso de un formato gráfico común para planos institucionales, incluyendo el cajetín y la identificación del sistema de representación correspondiente.

## Archivos disponibles

| Archivo | Sistema de representación | Unidades |
|---|---|---|
| `ISO 1erD EIM PUCV.idw` | Primer diedro (first-angle projection) | mm |
| `ANSI (mm) 3erD EIM PUCV.idw` | Tercer diedro (third-angle projection) | mm |

## ¿Cuál plantilla utilizar?

- **Primer diedro:** utilizar `ISO 1erD EIM PUCV.idw`.
- **Tercer diedro:** utilizar `ANSI (mm) 3erD EIM PUCV.idw`.

La selección debe realizarse de acuerdo con el sistema de representación requerido para el plano.

## Contenido del formato

Las plantillas incorporan un formato institucional para planos técnicos con campos destinados, entre otros, a:

- identificación de dibujo, revisión y aprobación;
- fecha y nombre/firma;
- formato y escala;
- unidad dimensional;
- indicación del sistema de proyección;
- acabado superficial;
- simbología de soldadura;
- tolerancias dimensionales y geométricas no indicadas;
- tratamientos térmicos y/o superficiales;
- identificación de hoja e índice de modificación;
- identificación institucional EIM — PUCV.

## Uso en Autodesk Inventor

Los archivos se distribuyen en formato nativo de dibujo de Autodesk Inventor (`.idw`). Pueden utilizarse como base para generar planos institucionales y, si corresponde, incorporarse a la ubicación de plantillas configurada en la instalación de Inventor del usuario.

> **Nota:** la versión específica de Autodesk Inventor con la que fueron creadas o validadas estas plantillas aún no se ha documentado en este repositorio.

## Alcance

Estas plantillas se publican como recurso de apoyo para la preparación de planos de carácter institucional. El usuario debe verificar los requisitos técnicos, normativos y de representación aplicables a cada documento antes de su emisión.

## English summary

Institutional Autodesk Inventor drawing templates for the School of Mechanical Engineering (EIM), Pontificia Universidad Católica de Valparaíso (PUCV). Two `.idw` files are provided for **first-angle** and **third-angle** projection drawings, respectively.
