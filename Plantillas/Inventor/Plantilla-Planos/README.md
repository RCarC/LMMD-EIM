# Plantillas de planos — Autodesk Inventor

Plantillas institucionales para la elaboración de planos técnicos de la **Escuela de Ingeniería Mecánica (EIM), Pontificia Universidad Católica de Valparaíso (PUCV)**.

## Archivos

| Archivo | Proyección | Unidades |
|---|---|---|
| `ISO 1erD EIM PUCV.idw` | Primer diedro | mm |
| `ANSI (mm) 3erD EIM PUCV.idw` | Tercer diedro | mm |

Ambas plantillas incluyen el cajetín institucional y campos para escala, unidades, revisión, tolerancias, acabado superficial, soldadura, tratamientos y control de modificaciones.

Los archivos se distribuyen en formato nativo de Autodesk Inventor (`.idw`) para su uso como base en planos institucionales.

> La versión de Autodesk Inventor utilizada para crear o validar estas plantillas es 2025.
