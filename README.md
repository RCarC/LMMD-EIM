# LMMD-EIM

Open collection of 3D models, prototypes, CAD templates, and technical resources for download and reuse from **LMMD - EIM**.

## Repository contents

### [CAD Templates](./Plantillas/)
Templates and technical resources for CAD workflows, including Autodesk Inventor drawing templates.

### [3D Prototypes](./Prototipos-3D/)
Downloadable 3D prototypes and related files. Depending on the project, folders may include STL, STEP, CAD source files, documentation, and reference images.

## Repository structure

```text
LMMD-EIM/
├── Plantillas/
│   └── Inventor/
│       └── Plantilla-Planos/
└── Prototipos-3D/
```

## Usage

Open the folder of the resource you are interested in and follow its README for file descriptions, requirements, and usage instructions.
